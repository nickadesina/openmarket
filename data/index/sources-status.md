# Source status

Checked 2026-11-04 from the build container (P2, `docs/prompts/v2/p2-edgar-ingest.md` steps 7 and 8). Each source is checked against the source rule (decision 0003 §4): served without a login, not disallowed by robots.txt, a public filing or a public page. A source that fails is not built and is not imitated.
